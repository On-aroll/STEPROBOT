# 旧 WSM-400-RHW 焊机桥 V1

**适用性更正（2026-11-19）：** 用户确认原代码连接 WSM-400-RHW，当前实机为 WSME-400-PLUS，通过原厂外置 ATR-EtherCAT 通信盒接入。`S32608055`、`S326087650094` 均来自该盒子的标签。下述 32 字节编码、热丝功能、量程与反馈定义仅作旧工程参考，尚未适配当前组合；不能按本页直接映射并放行输出。新版安排见 [PLC 布置与下一步](../welder_wsme400plus_r1/PLC布置与下一步.md)，读取程序见 [WSME 400PLUS 接入重写](../welder_wsme400plus_r1/README.md)。

所有地址均为 Modbus PDU 的0起始 HR 偏移。接口只接受已有机器人主桥登记的本机会话；不会建立第二个机器人控制会话。

命令：HR7000起32 WORD，单个FC16。WORD0=`0x5742`，1=1；2/3请求号、4/5主桥会话号、6/7PLC启动标识，均高字在前；8操作（1控制、2参数、3全关）；9控制位；10…29为20个参数；30保留0；31校验=`0xA55A XOR WORD0 … XOR WORD30`。请求号须严格增加，原请求不会因许可恢复而重新执行。

控制位0起弧、1机器人/焊机准备、2检气、3热丝使能。热丝交流、高频方式与气冷方式属于参数18，不混入控制字。操作3在本机会话与启动标识正确时始终可关闭输出。

参数0…17按顺序为：操作方式、工作模式、电流×10、热丝Hz、热丝A、前气秒×100、延气秒×10、爬升秒×10、衰减秒×10、脉冲Hz×10、占空比×10、峰值A×10、基值A×10、起弧A×10、收弧A×10、交流Hz、清理比例设定、交流偏置设定。参数18的bit0为热丝交流、bit1为提升引弧（关闭高频）、bit2为气冷；参数19保留0。参数全部校验通过才整体应用，工艺输出非0时拒绝改参数。

状态：HR7200起64 WORD。

| WORD | 含义 |
|---|---|
| 0/1/2 | 标识0x5742 / 版本1 / 扫描计数 |
| 3 | 标志：bit0已安装，bit1映射确认，bit2PDO有效，bit3基础许可，bit4主机租约有效，bit5起弧许可，bit6本地工艺许可 |
| 4/5 | PLC启动标识，高字在前 |
| 6/7 | 已处理请求号，高字在前 |
| 8/9 | 结果：1应用、2拒绝 / 原因码 |
| 10 | 当前已应用控制位，起弧请求不等于引弧成功 |
| 11 | 原工程D500反馈状态位：引弧、就绪、焊枪异常、热保护、缺水、热丝热保护、热丝通讯异常、总报警、电流有无 |
| 12/13 | 焊机报警原始字节 / 已处理操作 |
| 14/15 | 当前主桥会话号，高字在前 |
| 16/17/18 | 电压V×10 / 电流A×10 / 热丝电流A×10 |
| 19 | 已读心跳 |
| 20…39 | 当前参数0…19 |
| 40…55 | 原32字节输入PDO，每WORD低字节在前打包两个BYTE |
| 56…63 | 保留0 |

原因码：1基础许可/通信/联锁，2控制位错误，3非外部自动或暂停，4准备或焊机就绪/无故障未通过，5检气与起弧冲突，6工艺输出未关闭，7参数越界，8操作无效。

心跳HR7064每250ms变化一次；PLC在1200ms无变化后撤销全部工艺输出。主桥失联、所有权变化、PDO失效、普通停止锁存、报警/急停、许可撤销同样撤销输出。故障解除不自动恢复；起弧/热丝在暂停、离开外部自动或作业结束后保持关闭。
