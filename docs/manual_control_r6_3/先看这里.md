# R6.3：放开全部手动速度入口

这次把PLC模式下关节、WORLD、指定位置和返回起点的额外低速上限统一放开，柜内服务的加速度参数也同步提高。上位机、PLC微调程序、柜内manual_service三部分配套更新。

## 可设置的速度

| 功能 | 输入范围 | 单位 |
| --- | --- | --- |
| J1～J6按住、单步 | 0.10～100.00 | 关节速度% |
| 指定绝对关节角 | 0.10～100.00 | 关节速度% |
| 返回保存的起点 | 0.10～100.00 | 关节速度% |
| WORLD按住、单步、指定绝对位置 | 0.1～3276.7 | XYZ为mm/s，ABC为°/s |

可以直接输入数值。关节提供11档至100%，WORLD提供13档，包含50、100、250、500、1000、2000、3276.7。启动默认值为1，按需选择。数值越大，请求速度越快。

3276.7是本版通信格式可表示的数值上限，不是SR175的额定速度。实际运动还取决于控制柜的轴/路径限制、示教器倍率、运动距离、加减速及分段等待；软件不强行更改示教器倍率。

## 这次还改了什么

**返回起点改为一次PTP返回保存的六轴位置**，不再每0.1°停稳、等待上位机再发一次。回程走关节PTP路径，不是TCP直线；运动前的确认保留。

柜内服务原先沿用很低的动态参数，现在设为路径加/减速度2000mm/s²、加加速度5000mm/s³，姿态加/减速度200°/s²、加加速度500°/s³，关节加速度、减速度和加加速度均为100%。每次运动的速度由界面输入覆盖；这些是本服务DYNAMIC变量，不修改控制柜系统配置。

按住按钮仍是柜内连续执行短段，每段结束检查请求和心跳。关节每段随速度为0.1/0.25/0.5/1°；WORLD每段为0.1/0.5/1/5/10mm或°。**松开后完成当前段才停**，高速WORLD档当前段最多10mm或10°，另有通信延迟。红色停止、失焦、通信失效继续走停止处理。

单步距离独立设置，仍为0.001～10.000°/mm。当前位置参考、填入目标、捕捉起点、清错、停止锁存处理保留。位置在停稳后更新，运动中显示“—”。
