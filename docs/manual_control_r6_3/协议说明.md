# R6.3速度协议

地址保持不变：命令HR220～235、状态HR400～431、位置HR450～489。协议版本2，微调修订号0603，能力字31；位置块修订号也为0603。

## 速度缩放

| 动作 | 速度字 | 实际请求值 |
| --- | --- | --- |
| 相对关节1～6、绝对关节30(kind1)、回程21 | 10～10000 | 除100，单位% |
| 相对WORLD11～16、绝对WORLD30(kind2) | 1～32767 | 除10，XYZ mm/s、ABC °/s |

操作7/action23先选目标kind；action24～29仍是六个有符号整数/千分小数分量，速度字此时表示小数部分，2000仍表示保持该分量。只有最终操作8/action30使用上述运动速度。不可对暂存字段应用速度缩放。

## 按住标记

上位机操作9的速度字为表中原值；PLC发向柜内时置位 `16#8000`。柜内AIRead若为负值，加32768还原；若为32768～65535，减32768还原。非按住的最高WORLD速度32767不会与标记碰撞。例如100%关节按住为42768，按有符号16位读取时为-22768；最高WORLD按住为65535或-1。

单步增量按1000缩放，上限10000(10°/mm)。按住段长按速度选择并在PLC和柜内复核：

| 关节速度字 | 每段最大增量字 |
| --- | --- |
| ≤500 | 100 |
| 501～1000 | 250 |
| 1001～1500 | 500 |
| 1501～10000 | 1000 |

| WORLD速度字 | 每段最大增量字 |
| --- | --- |
| ≤50 | 100 |
| 51～250 | 500 |
| 251～1000 | 1000 |
| 1001～5000 | 5000 |
| 5001～32767 | 10000 |

松开撤销token并继续租约，等待当前段完成和新鲜回执；超时升级普通停止。未预排多段运动。旧加10000的R6.2按住编码不能与本版混用。

## 服务和回程

普通AO5签名为 `1000+heartbeat(0..61)*16+flags`，有效范围1000～1999；AO6接受token、AO7完成token、AO8错误×1000+起点编号保持原格式。位置快照header仍为28000+编号×32+分量，AO5与AO8相同才提交。

回程action21保留起点编号匹配检查，改为一次 `PTP(msHome,msDyn,NULL,Default,WORLD)`，等待完成后比较六轴误差0.005°。上位机收到完成后不会按AtHome状态自动重发；PC回程/绝对运动超时123秒，PLC运动总超时120秒。

本版柜内DYNAMIC初值为 `{1,2000,2000,5000,1,200,200,500,1,100,100,100}`。速度字段运行时赋值；WORLD速度超过100时仅将无关的JointVelocity字段保持在100%以内，PathVelocity/OriVelocity保留用户请求值。控制柜仍决定实际可执行速度。

会话所有权、动态主/扩展心跳、柜内租约、外部自动、加载确认、使能、报警/急停及停止锁存检查继续有效。
