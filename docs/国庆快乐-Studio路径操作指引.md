# 用 Studio 路径功能让机械臂写出"国庆快乐"（操作指引）

> **思路**：把字形轮廓做成 DXF 导入 Studio → 用 Studio 的**路径功能**（曲线投影）生成路径 →
> **路径仿真** 让机械臂在 3D 视图里写字 → 勾选 **TCP 轨迹** 高亮显示 → **路径输出** 直接生成机器人程序。
> 全程使用 Studio 自带功能，不需要任何自研程序。
>
> 依据：`1STEPStudio使用说明书V4.7.0` §4.2.7 曲线投影路径（"投影曲线可利用第三方软件绘制"）、
> §4.3 路径设置、§4.4.1 路径仿真/输出（"路径输出成功后将在 HMI 中生成机器人程序"）、§3.2.3 TCP 轨迹。

---

## 0. 准备

| 文件 | 说明 |
|---|---|
| `reports/guoqing_kuaile.dxf` | **要导入 Studio 的字形轮廓**（295 条线段，R12 DXF，单位 mm，字高 260mm） |
| `reports/guoqing_kuaile_path.json` | 同一路径的 JSON 版（供自研工具/3D 视图使用） |

生成脚本：`tools/glyph_to_path.py`（字体轮廓 → 路径点）、`tools/glyph_to_dxf.py`（→ DXF）。
改字号/字距/内容，改脚本顶部参数重跑即可。

---

## 1. 导入 DXF

1. 启动 Studio（`START-STEPSTUDIO.cmd`），打开/新建一个工作站
2. **文件 → 导入**，选择 `reports/guoqing_kuaile.dxf`
3. 导入后 3D 视图里出现"国庆快乐"四字的轮廓曲线（图层 GUOQING）
4. 用移动/旋转把曲线组摆到写字位置（贴到写字面/板上）

> 若导入对话框没有 DXF：手册 1.x 说支持 `.iges/.igs/DXF`，如遇问题告诉我，我可以改出 IGES 版本。

## 2. 如果场景里没有"写字面"

路径的投影需要一个面（法向决定路径点姿态）：

- 建模 → 创建一个薄长方体（写字板），尺寸建议 ≥ 1300×400mm，摆在机器人前方
- 或者直接用曲线不投影：**§4.2.8 曲线路径** 支持直接拾取曲线生成路径（需指定参考面给 Z 向）

## 3. 创建路径（§4.2.7 曲线投影路径）

1. **路径 → 曲线投影路径**
2. ① **拾取曲线**：框选四字的全部轮廓线（支持多条，数量不限）
3. ④ **拾取面**：选写字板的面
4. ⑤ **预览投影曲线** → 曲线被投影到面上
5. ⑧ **参数设置**：最小距离 5mm、公差 0.5mm（字会更大更精细）
6. ⑨ **预览** → 3D 视图里出现路径点
7. **确认创建路径** → 左侧布局树出现路径节点

> 也可以用 §4.2.2 特征线路径 / §4.2.8 曲线路径，看哪个顺手。

## 4. 让轨迹高亮显示（§3.2.3）

- 找到 **TCP 轨迹** 勾选项（3.2.3 节）→ 勾选后，机器人末端运动时会**实时显示轨迹线**
- **清除轨迹** 按钮可一键清除

## 5. 路径设置（§4.3）

路径设置里确认三项：

- **机器人**：SR175-3200
- **工件坐标**：投影所用面的参考系
- **工具**：Default（当前工具）

## 6. 路径仿真 / 输出（§4.4.1）

1. 勾选创建好的路径
2. 点击 **路径仿真** → 机械臂在 3D 视图中沿路径运动，TCP 轨迹高亮画出"国庆快乐"
3. 满意后点 **输出** → **Studio 自动在 HMI 中生成机器人程序**
4. 该程序可在示教器/HMI 中直接运行（真机同样适用）

## 关节限位参考（J2/J3 接近限位时注意避让）

J1 ±183° / J2 −60°~+85° / J3 −130°~+80° / J4 ±220° / J5 ±125° / J6 ±360°
（来自 `RobotParameter.xml`，已被控制器自身 FK 在零位证实：X=2066=L6+L4+L5，Z=2264.5=L1+L2+L3）

## 如果要换字/换内容

改 `tools/glyph_to_path.py` 顶部 `TEXT = "国庆快乐"`（任意中文），重跑：

```bash
python tools/glyph_to_path.py      # 生成路径点 + C++ 头文件
python tools/glyph_to_dxf.py       # 生成 DXF
```
