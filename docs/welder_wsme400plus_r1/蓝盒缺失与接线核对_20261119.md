## 当前判断

- 读取黑盒身份、CoE 映射和 EtherCAT OP，能证明 PLC 与黑盒之间的相应通信成立，不能代替黑盒与焊机的通信验证。
- 当前读值为每方向 **16 字节，不是 16 位**；其中 15 个对象 BYTE 加 1 BYTE 填充。缺少两个蓝盒并不提供“每盒 16 字节、合计 32 字节”的依据。此映射仍是黑盒当前报告的 CoE 配置，变化原因与硬件最大能力均未确定。
- 两只光纤接口可能用于一条链路的两端，不应直接假设为两个 EtherCAT 从站、两个 16 字节扩展模块，或分别对应两个焊接功能。该拓扑需要沿参考装置实际线缆核对。
- 没有蓝盒不自动证明当前不可用：如果这一版黑盒与 WSME-400-PLUS 提供相互兼容的直接电接口及配套线缆，可能可以直连；如果其配套方式要求光纤链路，则缺少接口硬件不能由改 XML 或 ST 代码补上。当前尚无直连兼容证据，也不能按插头外形一致认定兼容。

## 电缆两端照片已补齐，下一步读取焊机反馈线索

**保持当前可读取黑盒的现场配置，不恢复焊接输出。** 已准备的 32 字节 ESI 留在离线副本，先从当前盒子的只读对象中观察输入，随后再验证实际 PDO。没有依据因蓝盒缺失直接要求购买或改线。

不必新增程序或下载，只在当前已经成功使用过的在线 CoE 页面操作：

1. 双击当前在线的黑盒从站，打开“在线 CoE”，保持从设备读取。
2. 展开 **0x6000（DI Inputs）**，先读 **:01 与 :02**，取得设备返回的当前值；若界面只显示布尔、类型不符或读取失败，保存具体界面/错误，不将其擅自转换为完整 BYTE。
3. 同时记录焊机前面板当前显示、工作模式及报警。先比较既有空闲状态，不要求起弧、接焊枪、开关焊机电源或发送命令。
4. **0x1A00 是映射表，不能代替 0x6000 的对象值。** 0x6000 的 SDO 返回也是盒子报告值，不能单独证明它与过程数据缓冲区一致或焊机链路有效；需结合面板、后续实际 PDO 和诊断继续确认。当前值全零或 Ready=FALSE 不能单独判定通信失败，也可能受缺焊枪等就绪条件影响。

旧代码对输入 Byte0、Byte1 的解释为状态和报警，按同协议前提可作为对照线索，不把尚未观测的读值预先当作这些字段。先不使用已停用的 PRG_WelderIo 来刷新输入，因为该程序同时会产生输出；也不直接假设旧映射变量在控制任务停用后仍持续刷新。

若后续证据显示盒子与焊机不通信，再依据接口标识、诊断和配套连接方式定位直连兼容性。照片本身不能完成针脚或协议确认，不凭外形改线。当前无需为缺少蓝盒重写控制代码，也不要求接焊枪才能执行本轮只读查看。

本次没有改现场工程、下载 PLC、写 PDO/SDO/EEPROM 或操作硬件。
