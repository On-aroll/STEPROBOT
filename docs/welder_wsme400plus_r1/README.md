ESI 一致性是优先检查项：核对设备身份、过程数据配置、每项索引/子索引/位宽/顺序、总长度及实际同步管理器配置。不能只比较文件名；ESI 的通用 Byte 名称不说明起弧位和电流单位。当前按用户确认的同协议前提复用旧字段实现，并通过实际反馈与本机功能核对其适用性。

| 项目 | 实机读值 |
|---|---|
| 设备名称 0x1008 | PIC24 EtherCAT Slave |
| 硬件 / 软件版本 | 0.7 / 5.1 |
| 0x1018:01 Vendor ID | 8 |
| 0x1018:02 Product code | 37458，即 0x9252 |
| 0x1018:03 Revision / :04 Serial | 1 / 1 |
| 0x1C12 / 0x1C13 | 各分配 1 个 PDO；:01 已核实为 0x1601 / 0x1A00 |
| 0x1601:00 / 0x1A00:00 | 各有 16 个映射条目 |
| Rx 全部对象数据项 | 0x7010:01…0F，每项 8 bit；随后 8 bit 填充 |

以上是 CoE 对象读值，不等同于已读取 SII/EEPROM 身份。`LAN9252` 是 EtherCAT 芯片/描述名称，不能说明焊接协议。原有奥太 XML 的 32 字节和通用 XML 的设备名称，都不能替代实际总线与应用反馈验证。

**条目数不能直接代替字节数。** 本次已读完所有条目并累加，确认两边各 128 bit/16 字节，其中末尾 8 bit 是填充。`0x1C32:00=32` 仍是该对象的子项数量，不是 PDO 输出字节数。测试中的其他布局为模拟数据，不覆盖本次实际读值。

## 程序做什么

`plc/PRG_WsmeProbe.st` 只调用 `CmpHCCom.ETC_COE_SdoRead`：读取身份、实际 Rx/Tx PDO 分配、所有映射条目，计算总位宽与字节数，并复读核对身份和映射。它不写 PDO、不写 SDO、不改从站状态，也不占用任何固定 Modbus 寄存器。

当前支持每个方向分配 **1 个 PDO、最多 32 项**。超出时明确报错，不截断、不猜测。程序每次手动触发读取一轮；无自动重试或周期重读。每次读取的库超时为 2 秒，另有 5 秒等待超时保护。

本程序不负责停弧或清除其他程序遗留的工艺输出。配置验证期间保留现场已停用的旧焊机控制调用，不因读取成功直接恢复输出。机器人主桥和运动程序不需要因此替换。

## 触发一次并看结果

在 **ATR-EtherCAT 盒对应的从站**「常规」页查看实际配置的 **EtherCAT 地址**，不是设备树顺序或 Modbus 地址。自动配置下第一站常见为 1001，但这里必须填现场值。

将下列变量加入监视：

| 变量 | 设置/用途 |
|---|---|
| `PRG_WsmeProbe.usiMaster` | 使用第 1 个 EtherCAT 主站时为 1；多个主站按实际序号填写 |
| `PRG_WsmeProbe.uiSlaveAddress` | 当前现场已核对为 1001，新版默认 1001；更换现场配置时按盒子的实际地址填写，0 不执行 |
| `PRG_WsmeProbe.xAbort` | 正常读取时 FALSE；TRUE 中止本轮 |
| `PRG_WsmeProbe.xStart` | 先写 FALSE，再写 TRUE，最后写回 FALSE；使用「写入值」，不要强制 |
| `PRG_WsmeProbe.xBusy / xDone / xError` | 忙 / 本轮读取完整成功 / 本轮失败 |
| `PRG_WsmeProbe.uiError` | 下表的诊断码 |
| `PRG_WsmeProbe.wErrorIndex / byErrorSubIndex` | 失败的对象索引和子索引，索引建议按十六进制显示 |
| `PRG_WsmeProbe.eLastReadError` | 库返回的原始 SDO 错误；仅 uiError=2 时表示本轮库错误 |
| `PRG_WsmeProbe.udiLastSdoAbortCode` | 最近一次终态的原始 SDO 中止码，建议十六进制查看；0 不独立代表通信成功 |
| `PRG_WsmeProbe.udiLastDataRead` | 最近一次终态返回的实际字节数，结束后保留 |
| `PRG_WsmeProbe.xReadBusySeen` | 本轮是否观测到原生读取功能块进入 Busy；停止后保留到下次启动 |
| `PRG_WsmeProbe.xReadDoneSeen / xReadErrorSeen` | 本轮是否观测到原生功能块 Done / Error；不等同于整轮 xDone |

`xBusy=TRUE` 时修改主站号或从站地址会中止本轮。忙时的启动脉冲会被忽略；成功/失败后需新的 FALSE→TRUE 才会重新读取。

当 `xDone=TRUE`，记录以下结果即可继续核对，无须猜字段：

- `udiVendor / udiProduct / udiRevision / udiSerial`。
- `wRxPdoIndex / wTxPdoIndex`、`uiRxCount / uiTxCount`。
- `uiRxBits / uiTxBits`、`uiRxBytes / uiTxBytes`、`xRxByteAligned / xTxByteAligned`。
- `aRxMap[0..uiRxCount-1]` 和 `aTxMap[0..uiTxCount-1]`，以十六进制记录。0 项时没有有效数组条目。辅助数组 `aRxIndex / aRxSubIndex / aRxBitLength / aRxBitOffset` 与 Tx 对应数组已拆出索引、子索引、位宽和位偏移。

数组下标 0 对应 PDO 映射子项 :01。描述符如 `0x70100108` 只表示“对象 0x7010、子项 1、8 bit”，不表示它就是起弧控制。失败时数组可能只有部分数据，**仅 xDone=TRUE 时才可把结果当作完整一轮读取**；成功也不代表焊接协议已确认或可以放行输出。

| uiError | 含义 |
|---|---|
| 0 | 无错误 |
| 1 | 主站号或从站地址为 0 |
| 2 | 库 SDO 读取失败，查看 eLastReadError |
| 3 | 返回长度不符合该对象的 1/2/4 字节类型 |
| 4 | 单 PDO 映射条目超过 32 |
| 5 | 任一方向的 PDO 分配数量不是 1 |
| 6 | 分配的 PDO 索引为 0，或条目的位宽为 0 |
| 7 | 忙时主站号或从站地址改变 |
| 8 | 用户中止 |
| 9 | 复读时身份、分配或映射不一致 |
| 10 | 等待 SDO 结果超过 5 秒 |
