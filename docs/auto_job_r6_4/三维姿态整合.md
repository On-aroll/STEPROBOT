# R6.4 三维姿态整合版

当前已在此版基础上增加 [连接即读轴角](连接即读轴角.md)：安装新增的三个PLC对象后，连接即可读取J1～J6，运行中也刷新三个页面。下面的“运动中保持快照”描述仅适用于旧PLC手动快照兼容通道。窗口标题已更新为“R6.4 实时姿态版”。

本次把“三维姿态支线 R1”的最新显示与布局合入 R6.4 双通道上位机。继续使用本目录的 `启动上位机R6.4候选版.cmd`；窗口标题为“R6.4 三维姿态整合版”。已打开的旧窗口需关闭后重新打开入口。

- **① 作业准备**：原始SR175-3200模型、金色轨迹和蓝色终点虚影在同一场景显示，支持起点对齐、旋转、缩放、适应视图和背景选择。
- **② 设备控制、③ 微调与起点**：常用窗口按左1/4操作、中央1/2模型、右1/4状态或起点排列。窄窗口保留操作与模型并排，状态区域移到下方滚动查看。
- **姿态数据**：与R1相同，PLC模式只读HR450～489的有效停稳快照；运动期间保留上一姿态。没有有效反馈时明确显示参考姿态。三维起点对齐只改变预览位置；实验起点仍由原有捕捉功能保存。
- **上传**：R6.4的PLC批量转传和电脑直传（SDK手册FTP方案）均保留；上传后仍由你点击登记、加载、确认加载、使能、运行。

**这次合并不修改PLC源码、协议、对象或配置步骤。** 你正在配置的R6.4 PLC文件仍适用。手动移动的协议、速度限制、目标移动、捕捉起点和回程控制逻辑沿用原实现；只调整面板布局。

新上位机位于独立目录 `native_plc_auto_r6_4_twin_candidate`；此前的 `native_plc_auto_r6_4_transfer_candidate` 和三维R1支线保留。完整候选包包含Qt OpenGL运行库和模型网格。模型轴向和零位仍需现场与示教器核对；预览不作为碰撞检测或运动验收。

本地验证覆盖24项CTest，包括两个上传方式、手动操作回归、快照全生命周期零写请求、原始模型、终点虚影、标准/小窗口/宽屏的居中布局、无横向溢出和关键按钮可见。截图与布局JSON在 `validation/`，均为离线测试。
