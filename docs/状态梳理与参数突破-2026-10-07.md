## 4. 突破一：连杆参数"口径"已定 ✅

上一轮的结论是"`RobotParameter.xml` 那组 `SRDist*` 不是标准 DH，**口径未定，不能直接用**"。

**本轮找到了口径的权威定义**：《STEP机器人配置软件使用说明书 V1.5.4》**图 4-2**（配置表单）与**图 4-3**（示意图）给出了 `Distance/Rotation` 字段与 `L1–L7 / a1–a6` 的**逐项对照**：

| 配置表单字段 | → | 符号 | 手册定义 |
|---|---|---|---|
| Distance base axis 1-2 in X | → | **L6** | 沿 1 轴 x 方向到 2 轴的距离 |
| Distance base axis 1-2 in Z | → | **L1** | 沿 1 轴 z 方向到 2 轴的距离 |
| Distance base axis 2-3 | → | **L2** | 2 轴轴线到 3 轴轴线的垂直距离 |
| Distance axis 3-4 | → | **L3** | 3 轴轴线到 4 轴轴线的垂直距离 |
| Distance wrist axis 1-2 | → | **L4** | 腕轴 1-2 距离（示意图中为 3 轴到 5 轴的垂直距离） |
| Distance wrist axis 2-TCP | → | **L5** | 5 轴轴线到 TCP 的 x 方向的距离 |
| Distance base axis 2-3 in Z | → | **L7** | 沿 5 轴 z 方向到 6 轴的距离 |
| Rotation base axis 1 / 2 / 3 | → | **a1 / a2 / a3** | 1/2/3 轴**初始角** |
| Rotation wrist axis 1 / 2 / 3 | → | **a4 / a5 / a6** | 腕 1/2/3 轴**初始角** |

> 手册原文对 a1–a6 的定义：**"表示机器人在上图所示的机器人位置中关节的角度，即机器人的初始角度。"**
> → 也就是说 **a1–a6 就是零位角**；SR175-3200 六个值全为 0，说明**零位即示意图姿态**。

### 4.1 SR175-3200 的实际值

`RobotParameter.xml` 的字段名与上表**逐字段一一对应**，因此可直接落值：

| 符号 | 值 | 来源字段 |
|---|---|---|
| L1 | **629.5 mm** | `SRDistBase1_2Z` |
| L2 | **1335 mm** | `SRDistBase2_3` |
| L3 | **300 mm** | `SRDist3_4` |
| L4 | **1511 mm** | `SRDistWrist1_2` |
| L5 | **225 mm** | `SRDistWrist2_TCP` |
| L6 | **330 mm** | `SRDistBase1_2X` |

**这解释了上一轮的一个疑点**：`SRDistBase2_3Z = 0` 当时被当成"多余的零"，其实它就是 **L7**。

## 10. 追加：关节轴线可提取性 —— 本轮已实测打通 ✅

上一轮把"关节轴线位置与方向"列为 C 线头号缺项（"STEP 只给外形，不含旋转轴"）。本轮**实测证明可以从 STEP 里提取**。

**原理**：关节的旋转轴 = 该关节处轴承配合**圆柱面的轴线**。STEP 明文里 `CYLINDRICAL_SURFACE` 直接带 `AXIS2_PLACEMENT_3D`（点 + 方向）。

**实测结果**（`tools/extract_joint_axes.py`，全程约 10 s）：

| 项 | 值 |
|---|---|
| 解析 | 825,478 行 / 649,265 个实体 |
| `CYLINDRICAL_SURFACE` | **3,272 个，全部解出轴线** |
| 主轴方向分布 | **Z: 1037 个**、**X: 970 个**、**Y: 745 个**（其余为斜置小面） |

**关键交叉验证**：半径 240 mm 的 X 向轴承孔成对出现在 `y=0` 与 `y=1335` —— 两条平行轴线间距**恰好 1335**，与 §4 的 **`L2 = 1335`** 完全吻合。

→ 也就是说：**"从 `RobotParameter.xml` 拿到的连杆参数"与"从 CAD 几何反推的轴线间距"互相独立地指向同一个数**。这是本轮对参数正确性的最强证据。

**仍待做**（下一步 B 的具体内容）：
1. 把 3,272 条轴线**按零件归属**分组（需要解 `NEXT_ASSEMBLY_USAGE_OCCURRENCE` 装配树），筛出每个关节的主轴承孔 → 得到 6 条关节轴线。
2. 求 **CAD 装配系 ↔ 机器人控制系** 的对齐变换（已知 J1 轴为 Z 向、J2/J3 轴为 X 向，且 J2–J3 间距 = L2）。

**探测产物**：`_extract/mesh/joint_axes_probe.json`（方向直方图 + 按半径排序的轴线明细）；脚本 `tools/extract_joint_axes.py`。
