## 日常使用

1. ①「作业准备」：点击左侧 **导入 G 代码并自动上传…**，在转换窗口只选择一次一个或多个G代码；如果已从顶部“打开文件”载入G代码，转换窗口直接带入该文件。新选择的文件转换通过且勾选自动上传时继续上传；遇到需要确认忽略的工艺输出，先在该窗口明确确认，再点击上传，不用重新选文件。主页面自动显示本次G代码原文、轨迹、程序对应关系、版本和上传状态，传输方式选择保留在导入窗口中。
2. ②「手动与起点」：连接 PLC 后直接在本页登记，加载10号、人工确认、使能、进入微调；按实验需要捕捉起点。登记与自动页共用同一个本机会话。
3. ③「自动运行」：退出微调、停稳后加载11号，确认加载、使能、运行。换 G 代码继续更新固定工程中的自动作业文件。
4. ④「焊机工艺」：焊机参数和独立工艺操作。此版没有把起弧自动绑定到 G 代码；自动作业仍为空跑。
5. ⑤「联动打印」：顶部横排登记、程序号、加载、确认和清错/复位；左侧运行与焊机操作按钮每行一个，连同电流电压反馈和焊机状态占约四分之一宽度；中间实时姿态与轨迹占一半；右侧焊接参数占约四分之一宽度，18项参数每行一项，辅助选项与读取、应用按钮置于其下。三维画面按可用高度伸展；全屏时两侧按钮、参数输入框和参数行距随多出的高度增大，减少底部空白。设备监视与详细日志收在下方展开区。

已检查1120×740、1520×920与1920×1040三种窗口尺寸：1520×920与1920×1040默认状态下，参数、姿态和主要操作按钮同屏显示，无需滚动；1120×740小窗口保留单列与文字大小，可通过页面上下滚动访问全部参数和按钮，无需左右滚动。展开详细监视或设备出现较长的状态/报警说明时也可滚动查看。

⑤页复用③、④页的原按钮、参数控件、通信客户端和本机会话。切页保留所选程序号、未提交的参数、回执和轨迹显示设置，不会自动加载、运行、起弧、收弧或重发输出。③、④页继续保留，可独立操作。

**「联动打印」目前完成界面合并，运动和焊接仍需分别操作。** 按轨迹自动起弧/收弧、焊接段与空移段同步尚未接入，本次没有修改机器人作业程序、G 代码转换或焊机 PLC 逻辑。

左侧不再提供“完整工程上传到新目录”的旧日常入口。新按钮会自动生成需要的机器人作业文件；可选择 PLC 转传或电脑 FTP 直传，两者均保留 PLC 回读校验。工程查看、编辑和导出 ZIP 保留在本地工具中。

自动作业默认显示本次转换使用的G代码原文。多文件时，在工程树各 `auto_01`、`auto_02` 子项内选择对应的G代码文件名，原文与轨迹一起切换；生成的SRP/SRD仍可查看。预览复用已转换的字节、参数和行映射，不再按默认参数重读磁盘源文件。转换失败时显示新文件的具体错误行，并清除旧作业的轨迹；上传中、失败和回读成功均分别显示状态。成功仍表示本次文件上传及回读通过，需要现场重新加载后核对版本。

2026-11-19现场文件 `dianzhen_R64_dryrun.nc` 的默认解析会在第438行 `M05` 报“工艺输出未接入”；上传窗口勾选忽略工艺输出后可转换成功。此前主页面另选同一文件会丢失该确认，再次报错；本版使用本次转换快照，避免重复解析导致的不同结果。未支持的G代码方言或尚未确认忽略的工艺输出仍会给出具体错误，不会被自动跳过。

第一页面三维视图上方的 **显示轨迹** 默认开启，轨迹使用带深色描边的金黄色高亮线，线宽按屏幕像素绘制，浅色、深色背景都可辨认。绿色点标示起点，青色点标示终点。取消勾选后保留姿态模型，隐藏轨迹和终点虚影。第一页单独记住此开关，关闭期间仍持续更新姿态和已导入作业。

自动导入成功转换后，第一页自动选择右上角 **轨迹细节 · mm**，以本次 G 代码范围取景，XYZ 保持相同比例。切换到 **机器人全景** 可查看模型与路径的位置关系。拖动旋转、滚轮缩放；点击 **适应视图** 恢复完整取景。第二至五页的姿态面板可在 **视图 / 背景 → 轨迹细节 · 按G代码范围缩放** 查看细小路径，也可切回 **机器人全景**。

焊机页宽屏按「工艺操作与反馈—机器人姿态—焊接参数」排列；窄窗口将焊接参数移到下方。参数表内部可上下滚动，读取与应用按钮保留在参数卡底部。

## 机器人模式

顶部新增 **机器人模式…**，可选择手动、自动、外部自动。

- 使用前先登记本机会话，退出微调，停止机器人、断使能，关闭焊机工艺输出。
- 切换模式使用独立厂家 SDK 组件，仅调用模式切换；PLC 继续负责加载、使能、运行、停止。
- 默认控制柜地址 `192.168.3.188:30312`，可在窗口中修改 IP。电脑必须能直接访问该地址；只有电脑到 PLC 的网路通，不代表 SDK 可以访问控制柜。本版没有修改电脑或 PLC 网络配置。
- 需要控制柜 SDK 回读与 PLC 模式反馈一致，界面才报告成功。超时或不一致时显示“结果待确认”，不会自动重发。
- **②页的微调服务依然需要外部自动。** 顶部切换“手动”是切换控制柜本身的操作模式，并不等同于进入10号微调服务。

## 焊机 PLC 接入

**机型更正（2026-11-19）：下面整节为旧 WSM-400-RHW 适配说明，尚未验证适用于当前 WSME-400-PLUS。** 实机通过原厂外置 **ATR-EtherCAT 通信盒**接入，`S32608055`、`S326087650094` 都是盒子标签上的编号；PLC 的 EtherCAT 从站是这个盒子。匹配这套盒子与焊机组合的字节协议仍待取得。当前上位机焊机页沿用旧适配，不应据其参数和状态判断新焊机。不要继续按下面的 32 字节表映射、置位许可或执行起弧/参数下发。新的 [PLC 布置与下一步](../welder_wsme400plus_r1/PLC布置与下一步.md) 和 [只读诊断](../welder_wsme400plus_r1/README.md) 已单独整理；完整控制适配尚未完成。

原程序来源为 `docs/工程文件/00_上下位机代码/Lower/lower.project` 中的 `GVL_Welders` 与 `CommPoll`，哈希及提取源码保存在 `docs/welder_r6_4/source_reference`。

旧焊机使用 HR300、HR400、HR500，现已被机器人主桥、微调及六轴反馈占用，因此不能把原工程整个导入当前 PLC。本次复用原32字节 PDO 编码、参数单位和反馈解析，另加独立地址和会话联锁。

在当前已跑通的 PLC 工程中添加以下对象，文件位于旁边的 `焊机PLC` 目录或工作区 `docs/welder_r6_4/plc`：

| 对象名 | 添加类型 | 粘贴内容 |
|---|---|---|
| GVL_Welders | 全局变量表 GVL | GVL_Welders.st 全部内容 |
| GVL_WelderBridge | 全局变量表 GVL | GVL_WelderBridge.st 全部内容 |
| PRG_WelderIo | POU → 程序 PROGRAM → ST | 子目录中的 declaration.txt 与 implementation.txt 分别粘贴到声明区和实现区 |
| PRG_WelderBridge | POU → 程序 PROGRAM → ST | 同上 |

`PRG_WelderIo` 是程序 PROGRAM，**不是功能块 FB**。只把 `PRG_WelderBridge` 加入与机器人主桥相同的周期任务，排列在 `PRG_RobotBridge` 后面。它会在内部调用 `PRG_WelderIo()`，不要再把后者单独加入任务，也不要让旧 `CommPoll` 同时写这套 PDO。

若编译提示“变量地址位于掉电保持区，必须同时包含 RETAIN 和 PERSISTENT”，用更新后的 `GVL_WelderBridge.st` 全文替换该 GVL：三个固定地址变量放在 `VAR_GLOBAL PERSISTENT RETAIN` 块内，`xMappingConfirmed`、`xWeldPermit`、`xPdoOperational` 放在另一个普通 `VAR_GLOBAL` 块内，默认 FALSE。不要把整张变量表都声明为保持变量。保持区中的旧请求仍受主桥会话、PLC 启动标识和变化心跳检查，状态区每扫描重建。

然后完成焊机 EtherCAT 从站的 I/O 映射：

- PLC → 焊机 RxPDO，Byte0…31：依次映射到 `GVL_Welders.g_byWeldOutMap01`…`g_byWeldOutMap32`。
- 焊机 TxPDO → PLC，Byte0…31：依次映射到 `GVL_Welders.g_byWeldInMap01`…`g_byWeldInMap32`。
- 使用标量别名选择映射，不手输数组下标。完整64项映射表见 `焊机_PDO映射.csv`。
- `GVL_WelderBridge.xPdoOperational` 必须由真实 EtherCAT 从站 OP 状态和有效工作计数驱动；不能用常量 TRUE 代替通信状态。
- 核对映射后，在 PLC 本地配置 `xMappingConfirmed`；按现场工艺许可驱动 `xWeldPermit`。这两个量默认 FALSE，上位机不会替你远程放行。

新增 Modbus 地址如下，均为从0开始的 HR 偏移，与当前主桥使用同一种地址解释：

| 范围 | 用途 |
|---|---|
| HR7000…7031 | 焊机完整请求帧，FC16 一次写32 WORD |
| HR7064 | 焊机专用续租心跳 |
| HR7200…7263 | 焊机只读状态与参数回读，FC03 读64 WORD |

如果 PLC 从站配置限制了可访问范围，请增加上述范围。现有 HR200/220/300/400/450/500 和文件桥 HR6000…6263 保留原用途。上位机必须读到 `HR7200=16#5742`、`HR7201=1` 与变化的扫描计数，才会开放新焊机操作。

接入后先确认焊机页状态、实际电流/电压、参数回读与示教器/焊机一致，再操作“开启焊机准备”和“检气”。“起弧”“热丝电源”分别有单独确认。填写参数不会输出工艺信号；应用参数需要全部工艺输出关闭。

失联、PDO异常、机器人报警/急停、停止锁存或撤销许可会撤销工艺输出；暂停、切离外部自动和作业结束会关闭起弧及热丝。恢复后不会自行重发起弧。**这些是普通软件联锁，不替代设备的实体急停。**

10号手动程序、11号入口、现有实验起点以及机器人 FTP 上传逻辑均不需要因界面改版重新配置。
