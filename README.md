## 开发与备份

- 重编上位机：在 `实验准备\上位机` 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`（先建原生桥，再建 C#、跑测试、发布到 `bin\host`）。
- 只检查本地 SDK：同目录 `run.cmd --diagnose`；虚拟控制器就绪后用 `capture-studio.cmd` 从 `127.0.0.1:30312` 只读采集。
- Git 忽略安装包、SDK 二进制、Studio 安装目录与生成产物；**Git 仓库不等于完整备份**。备份时须保留被忽略的 SDK、模型、原始手册、工作站与实验日志，并核对数量/大小/SHA-256。
