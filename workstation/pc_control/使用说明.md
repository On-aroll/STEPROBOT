# STEP 打印作业台 · 使用说明

适用版本：融合版 StepWorkstation.exe（三模式合一）。本说明面向操作者，按实际操作顺序编写；构建与开发信息见 [README.md](README.md)。

> **安全第一**：真正的急停是**示教器/控制柜上的实体急停按钮**，任何软件按钮都比不上它快。开始任何作业前清场，确认机器人工作范围内无人、无障碍。

---

## 1. 启动

双击运行目录下的 **`Open_Pendant.cmd`**（位于 `RobotPrograms\SR175_3200_Helix\pc_control\`）。它会启动 `native\StepWorkstation.exe`，出现主窗口：

| 区域 | 位置 | 内容 |
| --- | --- | --- |
| 工具栏 | 顶部 | 连接方式下拉、地址框、连接/断开按钮、打开文件、空跑勾选 |
| 作业原文 | 左侧 | G 代码 / SRP 源行，带行号，可直接查看 |
| 中部选项卡 | 中间 | **轨迹预览** / **手动点动** / **相机预览** 三个页 |
| 运行控制 | 右侧 | 开始、停止、暂停、复位、上位机起点/回程、Modbus 信号组 |
| 状态区 | 底部 | 指引文案（「下一步 · …」）、遥测回读、日志 |

窗口底部有一条**指引文案**，随时告诉你当前该做什么——不知道下一步干嘛时先看它。

---

## 2. 三种连接模式怎么选

工具栏下拉框三选一：

| 模式 | 连到哪 | 什么时候用 |
| --- | --- | --- |
| **STEP 虚拟控制器** | 本机仿真（隔离端口 30316/30317） | 第一次跑流程、改了 G 代码要验证、没有实机时。**不碰真机器人，随便试。** |
| **实机 STEP SDK** | 控制柜端口 30312 | 真机器人作业：点动、启停、程序加载、轨迹回读全部可用 |
| **Modbus TCP** | 机器人从站（默认 `192.168.39.220:502`） | 与 PLC（汇川 AC802）联动、或只需用系统信号直控机器人的场合。无实时回读 |

切换模式会自动换地址框内容（虚拟/实机共用控制柜 IP，Modbus 用从站 IP），**软件会记住你上次填的地址、程序号和位号设置，下次启动自动恢复**，不用重填。每次只连接一种。

**建议的第一次使用顺序**：虚拟控制器跑通全流程 → 确认 G 代码和作业没问题 → 再上实机。

## 3. 流程一：虚拟仿真（先跑通它）

前提：本机装有 STEPStudio 4.7.0，且仿真种子工程（`luoxuan-sim-20261104`）在位（装好后自动找到，无需配置）。

1. **打开作业**：工具栏「打开文件」→ 选择 `.nc/.gcode` 等 G 代码文件或 STEP 工程 ZIP。没有现成的就用作业模板 `SR175_3200_Helix_Ready_25mms_v4.zip`（已含 25 mm/s 速度档）。
2. **查看工程树**：左侧出现主程序/前置/变量树；中间「轨迹预览」页可等轴 / XY / XZ 查看**计划路径**。
3. **选「STEP 虚拟控制器」→ 点连接**。软件会拉起 STEPStudio 内核，加载种子工程并载入当前作业。连接后轨迹页叠加**回读轨迹**（虚线为计划、实线为实际）。
4. **点「开始」**：弹出确认窗，确认后虚拟控制器执行作业，源行视图跟随高亮当前行。
5. 结束后可在右侧实验区**回放本次试次**（见第 9 节）。

改了 G 代码想换起点：**断开连接后，在左侧源行视图双击某一行**即可从该行重新编译（仅直接打开的 G 代码文件支持；ZIP/SRP 原生工程不支持双击设起点）。

## 4. 流程二：实机 SDK 控制

### 一次性准备（只做一次）

1. **把作业工程存入柜内**：上位机的 G 代码作业存在 `GcodePreview.sr` 工程里，SDK 没有远程传文件的能力，需要先在「工程/工具 → G 代码转换」里把 G 代码转成工程 ZIP，用 U 盘（或 STEPStudio）导入柜内程序库。**之后每次运行都不用再传**。
2. 若要做**手动点动**，控制柜需有 `RobotParameter.xml` 速度档案：从示教器把该文件复制到工作区 `tmp\pendant_ui_runs\` 后重连即可（没有的话点动不可用，启停不受影响）。

### 机器人侧准备（每次上实机都检查）

1. 钥匙开关切到**自动模式**，运行方式选**连续**。
2. **伺服使能**（示教器上确认已上电）。
3. **倍率 > 0**。

> 柜内载入什么程序不用管：上位机点「开始」时会自动卸载旧程序并加载作业程序；也可以先点右侧「**加载作业程序**」手动切换（要求柜内程序处于停止状态）。

### 上位机操作

1. 下拉选「**实机 STEP SDK**」，地址框填控制柜 IP → 点连接。连接后显示版本核对信息，并**比对控制柜当前程序与上位机工程**（不一致会提示，点开始时自动切换）。
2. **首次使用记录打印起点**：手动把机器人挪到打印起点 → 点「**记录上位机起点**」。这一步会同时把起点写进柜内程序（homeSaved/pHome），是启动自检「起点检查」的前提；只记录上位机、没写进柜内时，启动会被拒绝并提示重新记录。
3. 中部「手动点动」页可选六轴 / WORLD / 基座 / 工具 / 用户坐标系，按住方向按钮点动，**单次最长 0.3 秒**，各轴实时角度回读。TCP 速度上限 250 mm/s。
4. 「上位机起点」区域可**预览回程**再看轨迹再确认，**回程 TCP 默认限速 25 mm/s**（可调），确认后才执行。回程**没有碰撞检测**，执行前确保路径上无障碍。
5. **「开始」**：确认弹窗后执行。软件先自动切换柜内程序，再自检前置条件（自动模式、连续运行、使能、程序在首行、倍率>0、起点已记录且当前位姿与起点一致），任一不满足会明确告诉你缺什么。
6. 运行中：停止 / 暂停 / 复位随时可用；急停永远走实体按钮。

## 5. 流程三：Modbus TCP 直控（PLC 联动）

Modbus 模式**绕过 SDK，直接写机器人的系统 IO 信号**。没有轨迹回读、没有实验记录——运行状态以示教器为准。典型用途：让汇川 AC802 PLC 或本软件当主站，按位号控机器人。

### 5.1 机器人侧一次性配置（示教器上做）

1. **配置 → 系统IO**：把启动/停止/暂停/复位/加载五个信号绑定到数字输入 DI（默认 DI33–DI37，可改）。
2. **GDI 组**：建一个 8 位 GDI 组绑定到 DI40 起的连续位号，并与**目标程序号**关联（程序号 1–255）。
3. 钥匙开关切到 **AUT EXT（外部自动）**。注意：「返回主程序」类复位仅在**外部自动且非运行状态**下生效。
4. 修改绑定后从站需**重置**才生效；从站最多允许 10 个连接。

### 5.2 上位机操作

1. 下拉选「**Modbus TCP**」，地址框自动填 `192.168.39.220:502`（改成实际从站 IP:端口）→ 点连接。仅允许私有网段（10.x / 172.16–31.x / 192.168.x）。连上后底部回读行显示轮询往返耗时和 DI 打包区校验；**AI 通道有信号时会直接列出数值**（如 `AI: AI5=123  AI7=456`），全部为零则显示「N 路模拟量全部为零」——接了传感器/PLC 模拟量时在这里看数。
2. 右侧出现 **Modbus 信号组**：
   - **程序号**：填 1–255 → 点「加载程序号」→ 软件把号码按 8 位二进制写到 GDI 位，再脉冲「加载」信号。
   - **启动 / 停止 / 暂停 / 复位**：与右侧主控按钮等价。
3. **「开始」**：弹确认窗后，先清掉停止/暂停电平，再脉冲「启动」信号。

### 5.3 信号语义（重要）

| 信号 | 默认位号 | 类型 | 行为 |
| --- | --- | --- | --- |
| 启动 | DI33 | 脉冲 | 拉高 600 ms 后自动回落 |
| 停止 | DI34 | **电平** | 点一次置高并**保持**（期间无法启动），再点一次解除 |
| 暂停 | DI35 | **电平** | 同停止，切换式 |
| 复位 | DI36 | 脉冲 | 拉高 600 ms 自动回落 |
| 加载 | DI37 | 脉冲 | 写完程序号后自动脉冲 |
| GDI 程序号 | DI40–47 | 8 位二进制 | bit0=DI40，值即程序号 |

位号不符时直接在界面上的 6 个「位号」输入框改（范围 DI33–96；GDI 组起始最高 89，因为 8 位不能越界），无需重启软件。底层寄存器为保持寄存器 Word1–4（地址 0–3）打包 DI33–96，bit0 为 DI33——与手册 V1.8.0 第四章一致，PLC 侧按同样映射写即可。

### 5.4 Modbus 模式的限制

- **无实时回读**：机器人位置、运行状态都看不到，运行结果以示教器显示为准。
- 手动点动、上位机起点/回程、实验记录全部置灰——这些操作请切回 SDK 模式或在示教器上做。
- 连接断开后需手动重连（SDK 模式的会话会自动重试）。

## 6. 轨迹预览与 G 代码工具链

- **轨迹页**：等轴 / XY / XZ 视角；蓝虚线=计划路径，绿实线=控制器回读轨迹（SDK/虚拟模式）。可拖动缩放。
- **G 代码转 STEP 工程**：「工程/工具」里有独立转换窗口（也可用命令行 `native\StepGcodeConverter.exe --input 文件 --output 程序.zip`）。生成含源行映射与哈希的完整工程 ZIP，送 STEPStudio 验证后再导入。
- **编辑工程内文件**：打开 STEP ZIP 后可编辑其中的程序文件——编辑的是本地副本，改完「另存 ZIP」导出，再送 STEPStudio 重新验证，**不要直接把改过的文件塞回原 ZIP**。
- **空跑勾选**：固定开启（跳过非运动行），保持默认即可。

## 7. 手动点动（SDK / 虚拟模式）

1. 切到「手动点动」页。
2. 选坐标系：六轴（关节）/ WORLD / 基座 / 工具 / 用户。
3. **按住**方向按钮点动，松开即停；单次动作最长 0.3 秒，防失控。
4. 实机点动 TCP 速度上限 250 mm/s；虚拟模式不限但同样单步。
5. Modbus 模式下本页不可用。

---

## 8. 上位机起点与回程（SDK 模式）

用途：打印结束后让机器人回到固定的打印起点，避免每次手动对位。

1. 手动把机器人挪到位 → 「记录上位机起点」（按控制器身份保存，换机器人互不干扰）。
2. 「预览回程」：轨迹页显示回程路径（六轴独立分段规划 + TCP 限速），先看再动。
3. 确认后执行回程：TCP 默认 25 mm/s，可调（0.1–250）。**无碰撞检测，路径上有东西就先清掉。**

## 9. 实验记录与回放（虚拟 / SDK 模式）

### 9.1 做一次实验

软件**自动记录**，不需要手动开关：

1. 开始前在右侧「记录」区**填试次备注**（如 `25mms-第一次`、`层高0.2-对照`）——不填也能记录，但之后对比时分不清哪次是哪次，强烈建议填。
2. 连接（虚拟或实机），点「开始」。软件自动创建一个试次文件夹，开始记录。
3. 作业跑完自动封存，日志区显示「实验记录已封存 · 文件夹路径」。

一次试次记录下来的东西（存到 `outputs\workstation_runs\`）：

| 内容 | 用途 |
| --- | --- |
| 作业输入快照 | 当时打开的 G 代码/工程，复现实验用 |
| 计划路径 | 转换后的目标轨迹 |
| trace.csv | 逐周期回读：时间、当前源行、机器人实际位置、**与计划路径的偏差** |
| 事件流水 | 启动/暂停/停止/断连等事件的时间线 |
| 摘要（metadata） | 结果（完成/停止/异常）、**RMS 偏差、最大偏差**、样本数 |

跑完后点「**打开本次记录**」直接跳到该文件夹；摘要里的 RMS/最大偏差是评价打印轨迹精度的核心指标，写报告直接引用。

### 9.2 对比两次实验（改参数看效果）

1. 第一组：填备注 → 跑一次 → 封存。
2. **只改一个变量**（比如速度档、层高、G 代码版本），填新备注 → 再跑一次。
3. 点「**历史试次**」打开回放窗口 → 在列表里选中两份试次 → 对比视图会并排显示两次的参数和偏差（RMS/最大偏差一目了然）。
4. 回放窗口里拖**时间轴**可以逐帧回放任意一次试次的轨迹推进，不用真跑机器人。
5. 做完一轮实验要写报告时，点「**导出汇总 CSV**」——把全部试次的开始时间、备注、结果、RMS/峰值/端点偏差拉成一张表，Excel 直接打开（自动带表头编码，中文不乱码）。

### 9.3 补充

- 「另存遥测 CSV」：手动点动和联调过程的遥测可单独记录成 CSV（作业试次的 trace.csv 是自动保存的，无需此按钮）。
- 断连/急停等异常结束的试次照常保留，摘要里结果字段会标 `stopped`/`ended_unverified` 等，别删——异常数据也有分析价值。
- Modbus 模式不记录（记录区会提示「Modbus 直控模式不记录遥测试次」）。

## 10. 安全须知

1. **实体急停永远优先**。软件的「停止」是普通程序停止，不是急停。
2. 「开始」前必确认：工作范围清场、工件已夹紧、程序号/程序核对无误。
3. 首次实机运行**降低速度**（作业模板自带 25 mm/s 档），确认轨迹正确后再提速。
4. 回程执行前必看预览；回程无碰撞检测。
5. Modbus 模式没有回读，**人不要离开示教器视线**，异常时直接实体急停。
6. 虚拟控制器模式物理上不可能动到实机，改代码、试参数放心在虚拟里做。

## 11. 常见问题

**Q：仿真引擎（STEPStudio）必须放在哪里？**
软件按「工作区根目录」找仿真引擎和临时文件夹，规则是：① exe 旁放一个 `workspace.txt`（内容写一行路径，如 `F:\STEPROBOTICS`）就以它为根；② 没有该文件时，若 exe 的上一级目录里有 `STEPStudio 4.7.0`，就以上一级为根（引擎放在安装目录里）；③ 都没有才回退老规则（盘根）。无论哪种，引擎的相对结构必须是 `<工作区根>\STEPStudio 4.7.0\STEPStudio 4.7.0\RobotController_PC\Environment\` 和 `<工作区根>\STEPStudio 4.7.0\STEPStudio 4.7.0\project\luoxuan-sim-20261104\`。改完 workspace.txt 重启软件生效。

**Q：点「开始」没反应/被拒绝？**
看右侧提示文案，会写明原因：机器人不在自动模式、没切连续运行、伺服未使能、程序没停在首行、倍率为 0、柜内程序没记录起点——逐项补齐即可。起点问题的解法：手动挪到打印起点后点「记录上位机起点」（会把起点写入柜内程序），再点开始。

**Q：界面提示「程序核对 · 不一致」？**
柜内载入的程序和上位机作业不是同一个。不用处理：点「开始」时自动切换；或先点「加载作业程序」手动切（柜内程序须处于停止状态）。若提示「柜内没有作业的工程文件」，说明工程还没导入过柜子——按第 4 节「一次性准备」做一次（U 盘或 STEPStudio）。

**Q：连接实机 SDK 失败？**
检查：① 控制柜 IP 填对没；② 电脑与控制柜在同一网段且能 ping 通；③ 端口 30312 没被其他上位机占用（SDK 只允许有限连接）；④ 防火墙放行。

**Q：虚拟控制器起不来？**
确认本机装了 STEPStudio 4.7.0 且安装目录里有种子工程；30316/30317 端口没被占用。启动内核需要几秒，不是卡死。

**Q：Modbus 连接成功但机器人不动？**
按顺序排查：① 示教器「系统IO」绑定做了吗；② GDI 组和程序号关联了吗；③ 钥匙开关在 **AUT EXT** 吗；④ 程序号「加载」了吗（光看 DI 电平不够，要先加载再启动）；⑤ 位号是否和界面设置一致；⑥ 修改绑定后从站重置了吗。

**Q：Modbus 轮询报超时/校验不一致？**
① 确认从站 IP、端口 502；② 从站连接数是否已达 10 个上限；③ 私有网段限制（公网地址直接拒绝）；④ 网络抖动时软件会按事务丢弃迟到响应，偶发一两次不用管。

**Q：G 代码打开后解析报错？**
左侧源行视图会标出问题行；常见是方言不支持（圆弧参数格式）或速度为 0。转换窗口里能看到逐条诊断。

**Q：双击源行设起点没反应？**
该操作仅对**直接打开的 G 代码文件**有效，且需先**断开连接**；ZIP/SRP 原生工程请在 STEPStudio 里改。

**Q：想换连接模式？**
直接下拉切换即可；如果当前已连接（无论哪种模式），先点「断开」再切换更稳妥。
