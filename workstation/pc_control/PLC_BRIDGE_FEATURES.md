# PLC桥接R3功能与边界

日期：2026-11-16。新增GDI8程序号1～255；兼容原V1四槽。完整升级步骤见PLC_BRIDGE_V2.md。

| 功能 | V1 PLC | V2 PLC |
|---|---|---|
| 可选择程序号 | 1～4，旧独立槽 | 1～255，GDI二进制 |
| 机器人侧输出 | FC16 offset0/1WORD | FC16 offset0/2WORD，单一通道 |
| 加载与运行 | 分离，加载后人工核对 | 保持分离，加载后人工核对 |
| 本地映射许可 | xCommissioned | xCommissioned + xGdiProgramMappingConfirmed |
| 期望DI监视 | DI33～48 | DI33～64，DI49～56为程序号 |
| 实际反馈 | DO33～96、AO5～32、XYZABC复用 | 保持一致 |
| 诊断 | HR300～363、会话/心跳/回执 | 加入能力、GDI字、端口与写字数 |

登记、使能、断使能、加载、人工确认、运行/继续、暂停、停止、清错、坐标请求、停止锁存复位、撤销会话共12条命令均有实际按钮。运行仍需独立确认。未开放任意DI/AI强制写、激光、送丝、原生点动或程序文件上传。

程序编号容量不是工程保存容量，编号绑定也不自动创建机器人程序。高编号只有在用户手动升级PLC、确认DI49～64空闲并完成机器人GDI绑定后才能实际使用。
