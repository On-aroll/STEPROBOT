## 联调发现与修正

1. 最初虚拟控制器未运行时，原生 SDK 连接返回 -4；上位机正确退出为 3，不报告采集成功。
2. 后续检测到虚拟控制器已启动。初版桥接误把 `ConnectStatus()` 当成布尔值，导致初始化成功后仍拒绝读取；核对本地头文件 `runStatus` 注释和实际返回后，按此版本 **0 = 正常**修正。
3. 控制器中文消息本来是 UTF-8，初版桥接按 ANSI 重编码导致乱码；现在优先保留有效 UTF-8，失败时才兼容 ANSI，4000 中文与 HMI 一致。
4. 分析器支持纯采集日志，并把离散终点偏差命名为“终点关节误差”，不称为整段轨迹跟踪误差。

没有证据确定先前 Studio 点击控制器无反应的原因。控制器在继续任务时已运行，不能声称由本次安装 .NET 或改 C# 代码修好了 Studio。
