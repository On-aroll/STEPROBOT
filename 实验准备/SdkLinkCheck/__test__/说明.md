# 桩件 SDK 冒烟测试

> **警告：这里产出的 `Robot-SDK-CSharp.dll` 是假的，仅用于测试 SdkLinkCheck 工具自身。
> 绝不能复制到 `libs\` 带到现场当真货用** —— 它会谎报 `init` 成功、谎报全部状态，
> 从而让阶段 1 的链路验收变成假阳性。

## 它验什么

`FakeSdk.cs` 的命名空间、类名、方法名刻意照抄《SDK使用说明 C# V2.3》，包含：

| 桩件内容 | 对应的验收点 |
|---|---|
| 12 个 `get*` 只读方法 | 白名单能否全部发现并调用，尤其 `getMotorEnableState()`（名字含 Enable）与 `getJogRefSys()`（名字含 Jog）——这两个曾被误杀 |
| `EnableMotorCmd` / `SetModeCmd` / `JogToRobotAxisposCmd` / `AllAlarmConfirmCmd` / `ProgramLoadCmd` | 黑名单是否真的拦住。每个被调用时都会打印 `[桩件调用] 方法名(参数)`，SdkLinkCheck 的输出里**不该出现任何一行**；上位机适配层在 `--allow-motion` 下**应该**触达它们 |
| `AXISPOS`（嵌套结构体 + `double[]`）、`RobotDI`（`ulong[]`）、`MessageData`（中文串） | 反射渲染嵌套字段、数组、中文是否正常 |
| `getCurrentLine()` 每次自增 | 差分轮询能否只打印变化事件 |
| `init(string, int)` 恒返回 0 | init 成功路径与重试逻辑 |

## 跑法

```bash
cd 实验准备/SdkLinkCheck
dotnet build __test__/FakeSdk.csproj

STUB="D:\\Desktop\\STEPROBOT\\实验准备\\SdkLinkCheck\\__test__\\bin\\Debug\\net8.0\\Robot-SDK-CSharp.dll"

# 需要一个本地端口冒充控制器（真 SDK 会向控制器发报文，工具在 init 前先做 TCP 预检）
powershell -NoProfile -Command '$l=[System.Net.Sockets.TcpListener]::new([System.Net.IPAddress]::Loopback,30400);$l.Start();$end=(Get-Date).AddSeconds(25);while((Get-Date) -lt $end){if($l.Pending()){$c=$l.AcceptTcpClient();$c.Close()};Start-Sleep -Milliseconds 30};$l.Stop()' &

# 1) 离线导出签名
dotnet run --no-build -- --dll "$STUB" --dump

# 2) 端到端只读轮询
dotnet run --no-build -- --dll "$STUB" --ip 127.0.0.1 --port 30400 --seconds 5 --interval 400

# 3) 断网路径（换没人监听的端口）
dotnet run --no-build -- --dll "$STUB" --ip 127.0.0.1 --port 30499 --seconds 2
```

## 2026-09-18 实测结果

- 构建：桩件与主工程均 0 错误（主工程 csproj 已 `Compile Remove="__test__\**"`，桩件不会被编进去）
- 轮询：白名单 12 个接口全读到（含 `getMotorEnableState → 0`、`getJogRefSys → eJoints`），
  **7 个命令接口全部被拒绝，输出中没有任何 `[桩件调用]` 行** → 安全闸有效
- 渲染：`getAxisPos : m_Joint=m_jointData=[7.02,-12.5,30,0,90,-180]`、
  `getMessageData : ... m_MessageString="机器人没有上使能"` 均正确
- 差分：`getCurrentLine` 每 400ms 打印一条变化，其余静止字段不刷屏
- 退出码：`--dump` → 0；断网 → 3；缺 DLL → 2（全部与 README 一致）
- 本轮抓到的真实缺陷：初版黑名单按子串匹配 `Enable`，把 `getMotorEnableState()` 误判为写接口跳过，
  已在主程序里改为"窄排除表 + 不得收录 Enable/Jog/Run/Stop/Alarm"

## 桩件已升级为微型仿真器

后来的上位机骨架需要"发出去的命令能读回来"，所以桩件不再只回固定值：
`EnableMotorCmd` 真的切换使能态（照手册的**切换式**语义）、`JogToRobotAxisposCmd` 记住下发的关节角并由
`getAxisPos` 回读、`OverrideSetCmd` 改变 `getOverride` 的返回值，状态用 `lock` 保护（轮询线程会并发读）。
同一份产物被复制成 `上位机/test-fixtures/Robot-SDK-CSharp.dll`，支撑 `ReflectiveAdapterFixtureTests` 的 12 个适配层测试。
