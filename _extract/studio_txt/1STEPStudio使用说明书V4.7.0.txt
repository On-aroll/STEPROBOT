第一章 软件安装与激活
1.1 推荐配置
软件占用主要取决于搭建工作站的复杂度。为了可以流畅的设计复杂工作站，推荐以下核心配
置：
CPU：推荐 Intel i7-14700K 及以上的处理器。
内存：推荐 32GB 及以上内存容量。
显卡：推荐 RTX 4070Ti 及以上等级显卡。

1.2 软件安装
软件安装采用向导式安装方式。安装步骤如下：
1）安装包为 exe 格式文件，双击可启动安装程序，如下图所示：

2）弹出【选择安装语言】界面，如下图所示。点击【确定】，进入下一步。

3）安装目录默认在：C:\Program Files (x86)\STEPStudio 4.7.0 下（数字为版本号）。用户可以点
击浏览选择其它安装位置，并注意安装所在硬盘有足够大的空间。安装位置确定后， 点击【下一
步】，进入“选择附加程序”页面。

6.1 真机连接
首先需使用网线将电脑与控制柜(第一个网口)连接。
然后进行 IP 配置。打开示教器 STEP->控制面板->IP，检查当前 IP 地址，机器人默认 IP 地址为
192.168.39.220。

根据机器人当前 IP 地址选择在示教器上修改控制器 IP 并重启或在修改电脑网口 IP。使得机器人
与电脑处于同一网段。
以修改电脑 IP 地址为例。将电脑 IP 设置为 192.168.39.220 同一网段内的其它地址，也就第 4 个
值设置为 0~255 范围内非 220 的值。

STEPStudio 操作软件使用说明书

其中 192.168.39 代表同一个网段，220 代表机器人的地址。
例如可设置为 192.168.39.2，子网掩码设置为 255.255.255.0。
在 Windows11 系统中，打开设置，在左侧选择网络和 Internent，然后选择右侧的以太网。进入
子界面后，点击 IP 分配右侧的编辑按钮。

在下拉框中将自动(DHCP)重选为手动，然后打开 IPv4 的开关，修改电脑 IP 地址与子网掩码。将
IP 地址改为 192.168.39.2，子网掩码设置为 255.255.255.0，然后点击下方点击保存按钮。其它选项
