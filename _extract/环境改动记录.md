### 想把工具链挪到 D 盘的话

不能剪切粘贴（注册表登记 + `vcvars*.bat` 里全是绝对路径）。正确做法是**先卸载再用 `--installPath` 重装**：

```powershell
winget uninstall --id Microsoft.VisualStudio.2022.BuildTools
winget install -e --id Microsoft.VisualStudio.2022.BuildTools --override "--quiet --wait --norestart --nocache --installPath `"D:\VSBuildTools`" --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

注意 Windows SDK 默认仍会写到 `C:\Program Files (x86)\Windows Kits`，要一并挪得在安装器的"安装位置"页里对着组件行逐个改路径（或改用 `winsdksetup.exe /features ... /L` 单独指定）。**目前 C 盘还剩 313 GB，移动的收益几乎为零，只是再等一次下载安装。**

**实测结果（不是"装完了"，是"验证能用了"）**：`research\cpp-starter\build_msvc.bat` 用 MSVC 编译 `main.cpp` 并**成功链接厂商静态库 `Robot-SDK.lib`**，产出 `robot_probe.exe`（700 KB），运行后正确报出连接失败（机器人未上电）。链接能过 = ABI 与工具链全对。

**踩出来的两条硬约束（详见 `research/cpp-starter/README.md`）**：
1. 必须用 `/MD`（多线程 DLL 运行库）。用 /MT 会报 `LNK2038 RuntimeLibrary 不匹配 MD_DynamicRelease / MT_StaticRelease`。厂商库就是 /MD 编的。
2. `main.cpp` 要存成 **UTF-8 带 BOM**（我们自己的文件按 UTF-8 读，GBK 的 SDK 头文件按系统 ANSI 代码页读）；**不要**给工程加 `/utf-8`。
